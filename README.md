
# Console Calculator in C#

## 📌 Description
This is a simple console-based calculator application written in C#.  
It allows users to perform basic arithmetic operations on multiple numbers using a separate method.

The project is designed to practice:
- Methods
- Arrays
- Loops
- Switch-case
- User input handling
- Basic error handling (division by zero)

---

## ⚙️ Features
- ➕ Addition of multiple numbers  
- ➖ Subtraction (chain subtraction)  
- ✖️ Multiplication  
- ➗ Division with zero-check validation  
- Clean and user-friendly console interaction

---

## 🛠️ Technologies Used
- Language: **C#**
- Platform: **.NET Console Application**
